## Findings

### Gate 2: Consistency / DRY

- **finding 1**: `src/fabulexa_forge/writers/csv.py:52` — `write_csv` computes `out_path = output_dir / f"{table_name}.csv"` inline rather than calling the `csv_output_paths` function defined 25 lines below it in the same module.
  Code: `out_path = output_dir / f"{table_name}.csv"` vs. `csv_output_paths(out, table_names, window_label)`'s `base / f"{name}.csv"`.
  Why it matters: every other naming function this sprint introduced (`csv_removed_dirs`, `csv_cursor_path`, `companion_artifact_paths`) is consumed by its own write path specifically so "the two can never disagree" (the design's own stated rationale, quoted in `csv_removed_dirs`'s docstring and `export_window`'s). `csv_output_paths` is the odd one out — its own writer doesn't call it, so a future change to one side's naming rule would silently diverge from the source-is-output gate that trusts the other side.
  Severity: **observation** — behavior is currently identical (test-verified in `test_csv_output_paths_matches_write_csv_actual_file`), tests are green, and the risk is latent, not active.

### Gate 5: Coverage

- **finding 1**: `tools/build_dataset_pack.py:123-124` — `except ConfigError as exc: raise PackBuildError(f"{prefix}{exc}") from exc` inside `_load_packed_config`, guarding `load_yaml_mapping(raw, "config", config_path)`, is never hit by any test. Every existing pack-builder config-refusal test (`test_config_neither_export_nor_stream_refused`, `test_config_loader_refusal_carries_dataset_and_config_prefix`) exercises a document that parses as YAML but fails a later check (missing `mode`/`streams`, or a field the loader itself refuses) — none supplies syntactically invalid YAML to hit the earlier `load_yaml_mapping` refusal.
  Severity: **observation** — an uncovered error path per the gate's own rule, but the code is a one-line straightforward wrap-and-reraise identical in shape to the already-tested `except ConfigError` two lines below it (line 134); the risk of an actual defect here is low.

## Recommendation
